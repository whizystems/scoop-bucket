# Scoop Bucket

Whizystems [Scoop](https://scoop.sh/) bucket.

## Installation

```powershell
scoop bucket add whizystems https://github.com/whizystems/scoop-bucket
scoop install rdm
```

## Available packages

| Package | Description |
|---------|-------------|
| [rdm](https://github.com/whizystems/redmine-cli) | Agent-first Redmine CLI with markdown-optimized output |
